# 品牌资源

原创设计，概念为「两条会话并存」：两个前后叠放的气泡，后面那个是保留的原会话，前面带尾巴的是从它分出的新分支。不使用任何现有产品的商标或图形，也刻意避开了「三点连线」这种会被误读为分享的图形。

- `logo.svg` — 主 logo（渐变背景），用于 README / GitHub Pages
- `icon.svg` — 应用图标源图（与 logo 同几何），所有 PNG 与 ico 都由它导出
- `app.ico` — Windows 多尺寸图标（16/24/32/48/64/128/256），供 exe 使用
- `icon-*.png` — 各尺寸 PNG，供 Tauri 打包与网页引用

配色：蓝紫 `#6C5CE7` / `#4A3FCB`，白色气泡。与前端 OKLCH 主色 `oklch(52% 0.19 262)` 协调。

导出方式：`icon.svg` 先渲成 512 透明 PNG，再按尺寸缩放；`app.ico` 由同一张母图一次写出多尺寸，避免逐尺寸手绘走形。

## 图标集

`icons.svg` — 4 个 24×24 功能图标，几何语言与 logo 同源：**实心消息节点 + 1.7 描边连线**，只用 `currentColor`，无填充色块。

| id | 含义 | 图形 |
| --- | --- | --- |
| `i-fork` | 分叉 | 一个来源节点分出两条路径 |
| `i-keep` | 保留 N 条 | 两个实心节点保留，末端空心节点排除 |
| `i-dual` | 双版本 | 两条并行轨道，节点错位 |
| `i-local` | 隐私本地 | 分叉链收在本机闭环内 |

用法：站点画在 40px 圆角底板上，图形占 24px；符号建议内联进页面（`file://` 下外部 sprite 会被 CORS 拦住）：

```html
<svg viewBox="0 0 24 24"><use href="#i-fork"/></svg>
```

新增图标沿用同一网格：节点 r 2–2.5、描边 1.7、四周留 2px 安全边。
